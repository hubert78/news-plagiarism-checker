Problem Statement & Methodology

In digital journalism, the pressure to publish breaking stories often causes newsrooms to republish competitor reporting, government agency press releases, and wire stories with minimal editing or source attribution. This project evaluates duplication across five prominent Ghanaian news portals: Ghanaweb, 3News, MyJoyOnline, Modern Ghana, and Yen Ghana.

Detection Pipeline

  1. Text Sanitization: Removal of HTML tags, punctuation, and non-alphabetic characters.
  2. Stopword Filtering & Stemming: Removal of standard English stopwords (179 words) and morphological reduction via Porter Stemming.
  3. TF-IDF Vectorization: Term Frequency - Inverse Document Frequency vector computation with smoothed IDF and L2 vector normalization.
  4. Cosine Similarity: Pairwise vector dot products generating symmetric similarity scores between 0.0 and 1.0.

Architecture

The web client is completely static and deployable directly on GitHub Pages. When running locally via python server.py, it can trigger the native Python scrapers in scraper.py. When hosted on GitHub Pages, it leverages client-side proxy scraping or GitHub Actions workflows.
